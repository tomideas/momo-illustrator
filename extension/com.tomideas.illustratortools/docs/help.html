Momo Tools v2.101

Adobe Illustrator CEP 擴充套件面板 · 畫板 / 顏色 / 文字 / 工具 · 最後更新 2026-06-19

安裝：將 com.tomideas.illustratortools 放到 ~/Library/Application Support/Adobe/CEP/extensions/，重啟 Illustrator 後在 視窗 > 擴充套件功能 開啟。

畫板

複製畫板 v1.1.2

複製選中的畫板及其所有內容，放在現有畫板正下方。

選擇畫板Shift 多選或輸入範圍（如 1-5, 8, 11-13）
名稱編輯勾選「重新命名複製的畫板」後，查詢→替換文字。例：查詢 FR_ 替換為 CN_
位置與間距左右間距 / 上下間距 / 整體位移。預設自動檢測

重新排列 v1.5.8

將畫板按網格重新排列，可自定義每行數量和間距。

每行個數逗號分隔（3,3,2 = 第 1 行 3 個、第 2 行 3 個、第 3 行 2 個）
間距左右間距 / 上下間距（pt）
放置位置選區左上 / 某畫板正下方（可偏移）

畫板更名 v1.2.1

批次或單獨重新命名畫板。4 種命名規則：

編號FR_{n} → FR_01, FR_02… 佔位符：{n}=序號 {i}=畫板號 {name}=原名
替換查詢原名字部分 → 替換為新文字。支援正則匹配
逐行逐行輸入新名稱，空行保留原名
字尾在原名末尾追加固定文字。例：字尾 _v2 → FR_01_v2

顏色

顏色標籤生成

選取物件後自動生成 CMYK 色塊標籤。可設定色塊尺寸、字型、排列方向、位置等。

顏色檢查

掃描檔案中的填色和描邊顏色，統計並標註不符合規範的顏色（如 RGB 混入 CMYK 檔案）。支援文字和形狀兩種物件型別。

顏色庫

管理多組 CMYK 顏色，支援：

提取從 Illustrator 選中物件提取顏色
增加手動輸入 CMYK 值新增
點選色塊應用到選中物件的填充
••• 選單新建/重新命名/刪除顏色組、排序、匯入/匯出 JSON

文字

文字樣式檢查 v8.1.8

掃描文字框，找出字型、字號、行距不一致處，用橙色框標出。支援同一字號/字型/顏色分組，可選文字框內部混合檢查。

文字溢位檢查 v5.9.3

檢測文字是否超出文字框（紅色 + 標識），用紅框標註。

三條規則：

M4a內容字數超出行字數（垂直溢位）
M8轉點文字後內容縮短（水平溢位）
M12段落高度超出文字框（尾端空段溢位）

尾端空白 / 空段檢查 v1.0.1

檢查文字框末尾多餘空格、Tab、空段落，用橙色框標出。

工具

網格系統 v1.0.0

在畫板上繪製網格參考線。3 種型別：

瑞士網格列數/行數 + 間距。適合排版設計
等分網格N 等分 + 間距 + 可選對角線。適合海報/封面
黃金比例斐波那契數列分割 + 雙軸模式。適合攝影構圖

支援 px/mm/pt 單位轉換、內邊距 4 邊同步、實時預覽圖層 _網格預覽、一鍵轉為 Illustrator 參考線。

批次頁碼

為多個畫板自動新增頁碼文字。可設定位置、起始頁數、自定義格式。

筆記 (Momo Notes)

多分頁筆記面板，支援 Markdown 表格、拖曳排序、內聯重新命名。最多 10 個分頁。

從主面板「筆記」按鈕開啟。需要在 Illustrator 重啟後手動開啟。

開發診斷工具

面板底部版本號 v2.101，連點 3 次 顯示以下隱藏工具。

溢位診斷

互動式逐框診斷：自動選取每個文字框並縮放，顯示指令碼判斷結果，詢問是否有紅色 +，最後輸出 FP/FN 對比報告。

尾端空白診斷

互動式逐框診斷：顯示尾端字元視覺化（↵=Enter, ·=空格），詢問是否應標記，輸出對比報告。

重置所有設定

清除所有顏色庫、筆記和工具偏好設定，恢復出廠狀態。
